## 实际打开验证

验收环境：Windows，WPS Presentation 12.0。

验证步骤：

1. 用 WPS COM 打开 `examples/test3-editable.pptx`。
2. 确认幻灯片数量为 10。
3. 另存为 PDF。
4. 使用 PyMuPDF 将导出的 PDF 逐页渲染为 PNG。
5. 检查文字重叠、裁切、越界、图片缺失、图表标签和页眉页脚。
6. 使用 `scripts/validate_pptx.py` 解包检查 Open XML 结构。

最终文件可以在 WPS 正常打开、浏览和另存。第 8 页两张图表可进入“编辑数据”修改；文字框、线条、卡片和图片均可单独选中。

## 限制说明

原 PDF 是最终栅格图，不含原 PPT 的字体、段落、分组、母版、动画或图表数据。图表数据根据页面可见标签重建；复杂插图不做有损矢量描摹，以独立裁片保留视觉质量。字体使用 `Microsoft YaHei`，在没有该字体的系统上可能发生替换。
